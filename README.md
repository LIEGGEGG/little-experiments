# little-experiments ✨

A collection of tiny things I made out of curiosity.

This is my public playground for small creative experiments — interactive posters, weird little tools, playful demos, and whatever I feel like building.

Some ideas start as random thoughts.
Some are inspired by things I love.
Some exist just because I wanted to see them come alive.

Nothing here is meant to be perfect.
This is a space for trying, making, and sharing.

More tiny experiments coming soon :)

## Why this exists

Because sometimes building a small weird thing is more fun than overthinking.

And because "what if I just make it?" feels like a good way to live.
