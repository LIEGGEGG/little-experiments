# TA Adventure

> 把一本工具书，做成一段真的想走完的冒险。  
> Turning a technical book into an adventure you might actually want to finish.

**在线体验 / Live:** https://lieggegg.github.io/little-experiments/TA_Adventure/

## 中文

最开始只是冒出一个念头：**工具书一定只能从第一页一路啃到最后吗？**

于是我把 Unity 官方电子书 *Unity for Technical Artists: Key Toolsets and Workflows — 2021 LTS Edition* 拆开、重组，做成了 **TA Adventure**。

这里有章节、知识节点、XP、练习、原书推荐阅读，还有一点点游戏感。读完整本以后，也给走到最后的人留了一个小彩蛋。

它不是零基础 TA 教程，我更愿意把它当成一张 **Technical Art 地图**：不用什么都会，但至少以后真的碰到问题时，你会想起来——“哦，这里好像有条路可以走。”

## English

This started with a small question: **does a technical book really have to feel like something you grind through from page one to the end?**

So I took Unity's official e-book *Unity for Technical Artists: Key Toolsets and Workflows — 2021 LTS Edition*, pulled it apart, reorganized it, and turned it into **TA Adventure**.

There are chapters, knowledge nodes, XP, small exercises, the book's recommended reading, and a little game-like progression. If you make it all the way to the end, there is also a small surprise waiting for you.

It is not a zero-to-one TA course. I think of it more as a **map of the Technical Art landscape**: you do not need to know everything, but when a real problem shows up later, maybe you'll remember that there is a path worth exploring.

### Generic Skill

After finishing this version, I also extracted the process into a reusable **Generic Skill**. It is not tied to Unity: the idea is to turn other technical books and tool manuals into similar interactive learning experiences while staying source-first instead of letting AI quietly invent a new curriculum.
